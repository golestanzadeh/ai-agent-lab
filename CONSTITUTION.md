# Project Constitution

These principles are intended to remain stable unless explicitly changed and recorded in `DECISIONS.md`.

1. **Repository is the source of truth.** Important project knowledge must not live only in chat history.
2. **No invented history.** Unknown facts remain unknown until verified.
3. **Evidence before confidence.** Consequential claims require sources or explicit uncertainty.
4. **Human control for consequential actions.** The system must not silently make high-impact external decisions.
5. **Traceability by design.** Important outputs should be linked to inputs, evidence, tools, and decisions.
6. **Evaluation is part of development.** An agent is not considered reliable merely because a demo works.
7. **Simple before complex.** Add agents, memory, tools, and infrastructure only when they solve demonstrated problems.
8. **Learning is a first-class deliverable.** The project must teach the underlying concepts, not merely produce code.
9. **Reproducibility matters.** Experiments and important results should be repeatable.
10. **Security and privacy are default constraints.** Secrets and unnecessary personal data never enter the repository.
11. **Decisions are explicit.** Significant architectural choices require a recorded rationale.
12. **The system must be auditable.** It should be possible to understand what happened after an execution.
